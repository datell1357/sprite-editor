# 외부 작업 ZIP 검증 — 2026-09-13

## 구분
runtime atlas의 구워진 결과는 재생 frames, frames-manifest의 추출 files는 candidates이다.
curation의 선택/변형을 추정하거나 코드를 실행하지 않는다. 추출본은 픽셀 정리가 적용된
상태일 수 있으며 고해상도 raw와 동일하다고 주장하지 않는다. raw/refs/sidecar는 원본 ZIP에 보존한다.

## 검사
- 선택 결과와 원본 후보가 서로 다른 픽셀·시간인 fixture에서 구분 유지.
- 후보 누락, 잘못된 FPS/경로, 경로 이탈, 중복 정규 경로, 복수 manifest,
  symlink, 압축 해제 크기 초과 및 클립 용량 오류는 게시 전에 거부.
- 실제 sprite-gen run을 ZIP으로 만들어 API로 가져옴: 재생3/후보3/총6자산.
- 원본 ZIP 다운로드가 입력 바이트와 정확히 같음.
- 브라우저에서 가져온 작업 열기→3프레임과 후보3개 표시, 재채택 시 중복 없음.
- ZIP 입력 탭의 안내와 파일 미선택 시 비활성 확인. 네이티브 filechooser 자동화는
  기존 지연 문제로 반복하지 않았으며 파일 선택부터의 UI 전체 왕복은 별도 미검증이다.
- 관련 브라우저 오류 미관찰. 실제 생성 제공자는 호출하지 않음.

원본 ZIP은 프로젝트 JSON 안에 포함되지 않는다. 다른 컴퓨터로 옮길 때 별도 다운로드한다.
미완성 raw-only run이나 여러 색상 variant의 manifest가 함께 있는 ZIP은 이번 지원 범위 밖이다.
