# 맵 채우기 검증 — 2026-09-13

- 상하좌우 연결된 빈 영역 또는 동일 assetId만 채운다.
- 다른 자산 경계, 대각선 영역, 다른 레이어는 유지한다.
- 숨긴/없는 레이어와 범위 밖 좌표는 무변경이며 동일 자산 채우기도 무변경이다.
- 큐 기반 순회로 128×128 전 셀을 처리하며 행 경계가 이어지지 않는다.
- 전체 맵 20,000 배치 상한 초과는 기존 프로젝트를 바꾸지 않고 오류로 보고한다.
- 브러시/채우기에서 실제 변경이 생길 때만 기록한다. 빠른 이벤트는 최신 작업 사본에 적용한다.
- 맵 이력은 배치/레이어만 복원한다. 이름·클립 등 다른 프로젝트 정보는 유지한다.

브라우저 localhost 테스트 공간에서 24×16 맵 채우기 384 배치를 확인했다.
같은 위치 재클릭 후 프로젝트 이름 변경→undo는 0 배치와 새 이름을 유지했다.
redo로 384 배치를 복원했다. 오류/경고 로그에 관련 앱 오류는 없었다.
실제 캔버스 screenshot을 view_image로 확인했다. 화면의 geometric 이미지는 검증 fixture이다.

프런트엔드 전체 14개 테스트 및 프로덕션 빌드 통과. 이번 변경은 backend를 수정하지 않았다.
Autotile 이웃 규칙을 생성·해석하는 기능은 별도 후속 작업이다.
