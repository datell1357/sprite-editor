# 방향별 모션 일괄 생성 검증 — 2026-09-13

검토한 저장 자산 1~8개를 각 방향의 기준으로 사용해 한 동작을 생성한다.
방향은 사용자 지정이며 이미지에서 자동 판정하지 않는다.

- 모든 참조·설정을 검증한 뒤 하나의 DB transaction으로 등록. 용량 초과,
  잘못된 두 번째 참조, 중복 방향, UUID 충돌 시 부분 등록 없음.
- HTTP POST → 202 응답 → 두 방향의 전 단계 완료 → 방향이 붙은 클립 결과 확인.
  실제 제공자 대신 로컬 프로세스를 사용하는 대체 생성기로 검사했다.
- 첫 방향의 생성 실패 후 다음 방향 정상 완료, 실패 자산 미게시 및 성공 자산 보존.
- 브라우저: 기준 미지정은 체크 불가, 선택·검토한 방향 수 반영,
  기준 이미지 변경 시 해당 체크 해제, 이용 권한 미확인 상태에서 실행 불가.
- 390×844 모바일 모달은 가로 넘침 없이 내부 세로 스크롤 사용. 닫기와 viewport 복원 확인.
  브라우저 경고·오류 로그 없음. 사용자의 프로젝트와 분리된 localhost origin에서 검사.

실제 계정 생성은 실행하지 않았다. 프레임 자연스러움과 방향 간 캐릭터 일관성은
실제 결과를 검토해야 한다. 제출 버튼을 통한 유료 생성 왕복도 아직 미검증이다.
HTTP 통합 검사는 임시 loopback 포트 바인딩을 허용하는 실행 환경이 필요하다.
