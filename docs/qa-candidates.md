# 프레임 후보 보관 검증 — 2026-09-13

재생에서 제외한 프레임은 같은 클립의 candidates에 assetId와 durationMs로 남긴다.
후보 복원은 목록 끝으로 이동하며 이미지 파일이나 다른 클립을 수정하지 않는다.
같은 assetId의 다른 재생 시간도 별도 항목으로 유지한다.

- 단위 검사: 제외/복원 시간 유지, 원본 객체 불변, 후보-only 참조 검증/복원,
  후보/재생 최대 256 제한, 잘못된 duration과 후보 형식 거부.
- 브라우저: 2프레임 중 375ms 항목 제외→후보 1개/재생 1개,
  새로고침 후 유지→복원 시 재생 2개와 375ms 확인.
- 실제 screenshot에서 후보와 편집 도구가 함께 보이도록 가로 도구 배치를 확인했다.
- 관련 브라우저 오류 미관찰. 프런트엔드 전체 23개 테스트 및 빌드 통과.

이 작업은 에디터 내 후보 관리다. 외부 sprite-gen raw/takes/curation sidecar 전체를
가져오는 기능까지 완료했다고 주장하지 않는다. 유료 생성 호출은 하지 않았다.
