# 첫 편집기 작업 단위 검증

2026-09-13. 전체 제품 완료 보고가 아니라 현재 편집 흐름의 검증 기록이다.

## 동작
- 실제 Pixel Snapper native build 및 PNG 처리 성공. 1254×1254→92×91,
  원본과 처리 결과를 별도 자산으로 유지.
- 브라우저에서 브러시 변경, undo, redo, 수정본 저장 확인.
- 서로 다른 수정본 2개를 타임라인에 추가하고 재생/정지 확인.
- 객체 레이어에 자산 2개 배치. 픽셀 크기를 강제 축소하지 않음.
- Export project 실제 파일 확인: 자산 3개, 배치 2개, 프레임 2개,
  모든 embedded PNG 크기 확인.
- local fixture 프로젝트 import 성공: 이름·자산·프레임 복원, reload 후 유지.
- 최초 Downloads 경로 import 시 파일 접근 실패. 파일이 실제로 사라진 상태였으며
  존재하는 ASCII /tmp fixture로 다시 검증해 성공.
- provider의 유료 생성은 미실행. CLI adapter가 있다고 생성 품질/계정 권한을 보증하지 않음.

## 화면 비교
Image Gen concept과 실제 브라우저 스크린샷을 view_image로 직접 비교했다.
데스크톱 1536×1024, 기본 1280×720, 모바일 390×844 확인.

| 비교 항목 | 결과/의도적인 차이 |
|---|---|
| 레이아웃 | 좌측 자산, 중앙 캔버스/타임라인, 우측 inspector 유지 |
| 팔레트 | graphite 배경, mint 선택/주요 동작, muted 텍스트 유지 |
| 도구 | 일관된 lucide outline, 선택/비활성 상태 및 접근 가능한 이름 |
| 이미지 | 실제 생성한 sample과 Snapper 결과 사용, nearest 렌더 |
| 글자 | 한국어 작업 설명 사용. concept의 영어 예시·가상 자산 숫자 그대로 복제하지 않음 |
| 캔버스 | 고정 zoom 대신 실제 자산과 화면에 맞춘 시작 배율로 보완 |
| 모바일 | inspector를 기본 접고 자산 목록을 아래 가로 rail로 이동 |
| 개념과 차이 | 실제 자산 데이터, undo/redo·수정본 저장, 작업 기록 추가. 아직 미구현인 기능은 버튼으로 위장하지 않음 |

브라우저 error/warn 로그에서 관련 앱 오류가 관찰되지 않았다.
생성 샘플과 screenshot은 로컬 artifacts에만 보관하고 공개 저장소에 자동 게시하지 않는다.
