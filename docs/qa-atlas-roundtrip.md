# 에디터 아틀라스 왕복 검증 — 2026-09-13

타임라인은 version 1의 `frames` 배열을 내보냈지만 가져오기는 sprite-gen의
`frame_layout`/`animation`만 허용해 자체 결과를 다시 열지 못했다.
기존 export 형식을 서버에서 정규화하고 UI의 클립 개수 검사를 함께 수정했다.

- 기존 JSON을 변형하지 않고 초 단위 duration을 ms로 변환한다.
- 프레임 좌표·PNG 한도·총 픽셀 수·셀 크기 검사는 기존 parser와 공유한다.
- plain/Pixel Unfake 표시, 이름, FPS, 반복 여부를 복원한다.
- PNG에 이미 구워진 offset을 다시 적용하지 않는다. 마지막 행의 빈 칸도 허용한다.
- 잘못된 duration·variant·좌표는 자산 게시 전에 거부한다.

브라우저 실제 내보내기의 walk 3프레임 PNG/JSON을 임시 저장소에 가져와
원래 자산과 RGBA 바이트가 같고 각 125ms, loop=true임을 확인했다.
불균등 시간 125/375ms와 부분 마지막 행은 회귀 테스트로 별도 검증했다.
프런트엔드 23개/Python 43개 및 빌드 통과. 안내 화면에 오류 로그 없음.

네이티브 파일 선택 자동화가 이전 회차에서 장시간 지연되어 반복하지 않았다.
UI의 파일 선택부터 완료까지의 자동화 검증을 통과했다고 주장하지 않는다.
아틀라스는 재생 셀의 스냅샷이며 후보·원본 관계를 보존하는 전체 프로젝트 백업은 아니다.
