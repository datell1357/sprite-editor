# 방향 기준 생성 연결 검증 — 2026-09-13

8개 명시적 방향 중 선택된 방향마다 기준 1프레임을 만든다. 방향별 action에 시점을
명시하고 sprite-gen directions 계약으로 준비한다. mirror 설정이나 래스터 반전으로
생성을 대체하지 않는다. 한 작업은 동일 deadline을 공유한다.

검증:
- 8방향 recipe/각 1프레임/명시적 시점/미러 없음/명시적 codex/concurrency 1.
- 요청된 방향, 셀 크기, 결과 개수, QA 및 빈 이미지 검증 후 게시.
- 결과 parentId가 입력 자산을 참조함.
- 잘못된/중복 방향, 이용 권한 미확인, 미지원 provider 거부.
- job 단계 완료 후에만 결과를 게시하는 연결 테스트.
- 실제 sprite-gen prepare 실행: 8개의 *_idle 상태와 각각 base-source 참조 확인.
- 브라우저에서 8방향 선택 및 이용 권한 미확인 상태의 생성 비활성 확인.
- 관련 브라우저 오류 미관찰. Python 전체35, 프런트엔드23 및 빌드 통과.

실제 생성은 호출하지 않았다. 방향 정확도·좌우 장식·자연스러움은 이미지 결과가
있어야 검증할 수 있으며 자동으로 승인하지 않는다. 사용자가 결과의 방향 기준을
선택하면 기존 단일 상태 애니메이션 경로로 이동한다.
